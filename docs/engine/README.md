# The simulation engine's records

Ghost Bear's Legacy runs on the MechWarrior 2 engine, and the port's simulation was first traced in that engine. Those
traces are kept here because the simulation's values still rest on them:

- **ASSUMPTIONS.md:** every value that is not taken straight from the original code, with its source and status.
- **AUDIT.md:** the audit log.

GBL's own differences are in [../gbl/](../gbl/): E_sim.md and J_sim_impl.md for the simulation, and the A-D specs for the
shell.
